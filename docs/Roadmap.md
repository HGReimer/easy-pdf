# Easy PDF – Roadmap

## Vision

Easy PDF soll die einfachste und schnellste PDF-Anwendung ohne Abo werden.

Unser Ziel ist es, möglichst schnell eine erste verkaufbare Version zu veröffentlichen, um Einnahmen für die Weiterentwicklung weiterer Softwareprojekte zu erzielen.

# Unser Grundsatz

Bei jeder neuen Idee stellen wir zuerst die Frage:

> Bringt uns diese Funktion schneller zur ersten Veröffentlichung?

Wenn nein, wird sie auf eine spätere Version verschoben.

# Erfolg bedeutet

Nicht:

"Version 1.0 ist fertig."

Sondern:

"Der erste Kunde hat Easy PDF gekauft."

Das ist unser erster großer Meilenstein.
